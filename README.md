# 🎰 Terminal Slot Machine Game

A simple CLI-based slot machine game built in Node.js.

## 🚀 Features

- Deposit money
- Choose lines to bet on (1-3)
- Set bet amount per line
- Spin 3x3 slot grid
- Win if all symbols in a row match
- Automatic balance update
- Replay or exit

## 🛠 Installation

### Prerequisites

- Node.js (v12 or higher)

### Setup

```bash
git clone https://github.com/your-username/slot-machine-game.git
cd slot-machine-game
npm install prompt-sync
node project.js
